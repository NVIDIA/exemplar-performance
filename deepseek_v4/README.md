# DeepSeek V4

This directory contains performance recipes for DeepSeek V4 pre-training workloads.

## Available recipes

### Flash

- **Path:** [pretrain/flash/](pretrain/flash/README.md)
- **Framework:** Megatron-Bridge
- **Supported GPUs:** GB300, GB200, B300, and B200
- **Precision:** FP8 with the MX recipe

See the [Flash README](pretrain/flash/README.md) for supported configurations, setup, and launch instructions.

## Planned recipes

DeepSeek V4 Pro recipes are planned for a future release.

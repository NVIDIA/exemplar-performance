# Scripts

Utility scripts for TaskTrace Capture development and testing.

| Script                        | Purpose                                                 |
| ----------------------------- | ------------------------------------------------------- |
| `check_arm64_compat.py`       | Check ARM64 compatibility of task images.               |
| `smoke_test_runtimes.sh`      | Quick smoke test across supported container runtimes.   |
| `test_github_connectivity.sh` | Verify GitHub connectivity from the current host.       |
| `build_nemotron_images.sh`    | Build and push Docker images for Nemotron task domains. |
